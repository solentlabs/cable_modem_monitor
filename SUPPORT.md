# Support

Cable Modem Monitor is maintained by one person, in the evenings, around a
day job. This page says what to expect and where to ask.

## What to expect

- **Replies.** I read every issue and Discussion. Replies are best effort;
  a few days is normal.
- **Reviews.** Pull requests are reviewed on weekends, with about a
  two-week turnaround. One PR per contributor is active at a time; see
  [CONTRIBUTING.md § Review pace and volume](CONTRIBUTING.md#review-pace-and-volume).
- **Fixes.** They land as time allows. A bug report with diagnostics or a
  HAR capture attached moves fastest, because it needs no back and forth.
- **Closing.** A thread that goes quiet is closed as bookkeeping, not
  rejection; a comment on it is still read and can reopen it. The rules are in
  [CONTRIBUTING.md § Issue Closing Policy](CONTRIBUTING.md#issue-closing-policy)
  and [§ Discussion Closing Policy](CONTRIBUTING.md#discussion-closing-policy).

## Where to ask

| Need | Go to |
| ---- | ----- |
| My modem is not in the catalog | [Modem request guide](docs/MODEM_REQUEST.md) |
| Something is broken | [Troubleshooting guide](docs/TROUBLESHOOTING.md), then a [bug report](https://github.com/solentlabs/cable_modem_monitor/issues/new/choose) |
| A question, or an idea to shape before any code | [Discussions](https://github.com/solentlabs/cable_modem_monitor/discussions) |
| A security problem | [SECURITY.md](SECURITY.md), never a public issue |

Users also help each other on the
[Home Assistant Community Forum](https://community.home-assistant.io/).
